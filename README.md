# SOLIS Dynamics — Brand Identity & Design System Portal

Welcome to the **SOLIS Dynamics Brand Book & Design System**. This interactive web portal houses all brand guidelines, color tokens, typography rules, logo construction specs, live typography playgrounds, real-world mockups, and vector asset downloads.

---

## 🚀 How to Launch the Brand Book

1. Simply double-click **[`index.html`](./index.html)** or open it in any web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
2. **Zero installation or runtime required**: It runs 100% locally out-of-the-box.

---

## ✨ Features & Interactive Tools

- **🧭 Real-Time Sidebar Navigation & Fast Search**: Instant fuzzy filtering for sections, tokens, and topics.
- **🎨 Interactive Color Architecture**:
  - 1-Click Clipboard Copying for **HEX**, **RGB**, **HSL**, and **CSS Custom Properties**.
  - WCAG 2.1 AAA / AA contrast ratings for accessibility.
  - Signature gradient generator.
- **📐 Logo Construction & Rule Inspector**:
  - Interactive stage with toggleable **Construction Grid Overlay**.
  - Background adaptability toggle (Dark vs. Light preview).
  - Visual **Logo Dos & Don'ts** guide.
- **✍️ Live Typography Playground**:
  - Real-time sliders for **Font Size**, **Line Height**, **Letter Spacing**, and **Weight**.
  - Live editable headline canvas.
  - One-click copy for the dynamically generated CSS snippet.
- **📱 Real-World Mockup Gallery**:
  - Executive NFC Matte Black Identity Card.
  - Mobile Telemetry & Energy Grid App UI.
  - Industrial Station Terminal screen.
- **📦 Asset Download Center & Token Exporter**:
  - Instant vector `.svg` downloads for **Master Color**, **Dark Monochrome**, **Light Monochrome**, **Monogram Symbol**, and **Favicon**.
  - 1-Click Design Token export to **`tokens.json`**, **`tokens.css`**, and **`tailwind.config.js`**.
- **🖨️ Print & PDF Export**:
  - Formatted with clean print styles (`@media print`).
  - Click **"Print / Export PDF"** in the sidebar or press `Ctrl + P` to produce an executive Brand Book PDF.
